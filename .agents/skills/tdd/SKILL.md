# Test-Driven Development (TDD)

Use this skill when developing new features or fixing existing bugs.

---

## The Red-Green-Refactor Cycle

1. **RED**: Write a failing test that clearly specifies the expected contract or reproduces the bug.
2. **GREEN**: Write the minimal amount of production code needed to make the test pass.
3. **REFACTOR**: Clean up code and test structure while ensuring the test suite remains green.
4. **REGRESSION**: Run the complete unit test suite to guarantee zero regressions across the codebase.
