## Анимации (вкусно, но не вульгарно)

1. **Hero — аудио-волна**: под заголовком пульсирующая полоска-волна из
   ~40 вертикальных баров (CSS keyframes, высоты по синусоиде со сдвигом
   фаз, цвет — градиент #3b82f6→#60a5fa, плавная непрерывная анимация).
2. **Scroll-reveal**: секции появляются снизу с fade+translate при
   попадании во viewport (IntersectionObserver, один раз).
3. **Терминал-печаталка**: в секции диагностики терминал «печатает» вывод
   команды jarvis doctor построчно (после попадания в viewport, ~25 мс/символ,
   мигающий курсор ▍). Вывод:
   ```
   $ jarvis doctor
   ✅ Python: 3.14
   ✅ Конфиг: config.yaml (схема ок)
   ✅ Словари команд: commands.json + apps.json
   ✅ DE/адаптер: OS=linux, DE=hyprland
   ✅ STT (whisper): model_size=tiny
   ✅ TTS (piper): бинарь + модель на месте
   ✅ LLM (ollama): qwen2.5:3b на http://localhost:11434
   Итого: 8 ок, 1 предупреждений, 0 ошибок
   ```
4. **Hover карточек**: border подсвечивается акцентом + лёгкий подъём
   (translateY(-2px)), transition 200ms.
5. Без параллакса, без частиц, без сторителлинг-скролла — только это.

**FAQ — аккордеон (shadcn Accordion), 6 вопросов:**
1. Чем это отличается от платных Джарвисов? — «Ничем не хуже, но
   бесплатно и с открытым кодом: весь код на GitHub, данные не уходят
   никуда, никакой подписки. Локальная Ollama — вообще без интернета».
2. Что нужно для запуска? — «Linux или macOS, микрофон, ~4 ГБ RAM.
   Для LLM — локальная Ollama либо API-ключ облачного провайдера».
3. Мои данные куда-то уходят? — «Нет. Распознавание и озвучка работают
   локально, телеметрии в коде нет. LLM можно держать полностью офлайн».
4. Он выполняет команды на моём ПК — это безопасно? — «Есть трёхслойный
   approval gate: опасные команды требуют подтверждения, катастрофические
   (rm -rf /, mkfs) заблокированы всегда — даже в самом расслабленном
   режиме. Все выполнения видны в интерфейсе».
5. Есть ли Windows? — «Нет. Linux и macOS. Для Windows посоветуй WSL2 +
   AppImage — но честно: лучший опыт на Linux».
6. Сколько это стоит? — «Ноль. Всё бесплатное: код открыт, модели
   локальные, нейросети, которыми он собран, — тоже халявные».
