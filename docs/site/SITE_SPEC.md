## 1. Паспорт проекта

- **Название:** JARVIS
- **Слоган (H1):** Личный Джарвис. Бесплатно. Локально. Твой.
- **Суть в одном абзаце:** голосовой ИИ-ассистент с открытым кодом для
  Linux и macOS. Управляет рабочим столом голосом, выполняет команды,
  отвечает через LLM (локально через Ollama или облачно), может сам
  выполнять задачи через bash-агент с безопасным approval gate. Плюс
  Telegram-бот для доступа из любого места, напоминания и диктовка.
- **Автор:** 15-летний разработчик, проект собран бесплатными нейросетями,
  ни одной строки кода написано руками (это можно честно написать — это
  главная фишка истории).
- **Репо:** https://github.com/casha-cashu/jarvis
- **Релизы:** https://github.com/casha-cashu/jarvis/releases/latest
- **Issues:** https://github.com/casha-cashu/jarvis/issues
- **Discussions:** https://github.com/casha-cashu/jarvis/discussions
- **Лицензия:** MIT
- **Текущая версия:** 2.7.0

## 2. Аудитория и тон

- Основная аудитория: линуксоиды (особенно Hyprland/CachyOS-комьюнити),
  гики, которым надоел платный «умный дом», подростки, которым интересно,
  как собрать своего ИИ.
- Тон: уверенный, с лёгкой иронией, без корпоративного буллшита. Обращение
  на «ты». Упоминание «бесплатно» и «локально» — обязательно в hero.
- Язык: русский (проект русскоязычный), можно добавить переключатель EN.

### 3.3 Возможности (6 карточек, текст готов)
1. 🎙️ **Голос** — Wake word «Джарвис», распознавание через Vosk или
   faster-whisper с Silero VAD, озвучка ответов Piper'ом.
2. 🖥️ **Управление системой** — Воркспейсы, окна, скриншоты, громкость,
   блокировка — Hyprland, KDE, GNOME, i3, Sway и macOS.
3. 🤖 **LLM + bash-агент** — Ollama локально или OpenAI/Anthropic/
   OpenRouter. Агент выполняет реальные команды с трёхслойным approval gate.
4. 💬 **Telegram-бот** — Спрашивай Джарвиса из любого места — тот же мозг,
   тот же bash-агент, только в мессенджере.
5. ⏰ **Напоминания и диктовка** — «Напомни через 10 минут» — и напомнит
   даже после перезапуска. Диктовка голосом в любое окно.
6. 🩺 **jarvis doctor** — Диагностика окружения одной командой: конфиг,
   аудио, модели, LLM — приложи вывод к баг-репорту.

### 3.4 Как это работает (секция доверия)
Пайплайн одной строкой-диаграммой:
`микрофон → wake word → STT → NLU/команды → LLM (+bash-агент) → TTS`
И три пункта про безопасность:
- **Approval gate** — опасные команды требуют подтверждения; катастрофические
  (`rm -rf /`, `mkfs`) заблокированы всегда, даже в «yolo»-режиме.
- **Санитайзер окружения** — API-ключи никогда не попадают в дочерние процессы.
- **Локальность** — Ollama работает без интернета; никакая телеметрия никуда не уходит.

## 6. Технические требования

- Один index.html (можно с инлайн-CSS) — без билд-степов, чтобы
  деплоилось на GitHub Pages из папки `docs/` на ветке main.
- SEO: title, description (см. §1), og:title, og:description, og:image,
  lang="ru", favicon из логотипа.
- Никаких трекеров и внешних JS-библиотек (кроме шрифтов).
- Производительность: Lighthouse ≥ 95 по всем категориям.
- Ссылки не ломать: все URL из §1 ведут на живые страницы.
- Разместить готовый index.html в `docs/` на ветке main — Pages уже
  включён (Settings → Pages → main → /docs).

## 7. Решения владельца (2026-08-30) — ПРИОРИТЕТ

Подтверждено владельцем, включить обязательно:
- **Стиль:** тёмный минимал (как в JARVIS) + анимации и эффекты
  (scroll-reveal, hover-подсветка карточек, пульсация — без перегруза).
- **Скриншоты приложения:** 3 штуки (чат / настройки / статус) — файлы
  будут добавлены в docs/screenshots/, предусмотреть места под них.
- **Живой терминал doctor:** разворачивающийся блок в hero или отдельной
  секцией, «печатает» вывод jarvis doctor построчно с мигающим курсором.
- **Анимация голосовой волны:** в hero (CSS keyframes, полоски).
- **FAQ:** аккордеон с 6 вопросами (контент в V0_PROMPT.md §FAQ).
- **История проекта:** да, но скромно — небольшая секция ближе к футеру,
  без пафоса.
- Стиль финальный: тёмный минимал + эффекты. Стек у v0: Next.js + Tailwind
  + shadcn/ui — идеально ложится на токены из §4.
