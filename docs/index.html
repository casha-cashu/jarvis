Личный Джарвис.
Бесплатно. Локально. Твой.

Голосовой ИИ-ассистент с открытым кодом: управляет рабочим столом, выполняет команды, отвечает через LLM и делает всё это голосом — без подписок и «конских денег».

Скачать v2.7.0 Исходники

Возможности

Всё локально, всё бесплатно, всё с открытым кодом.

🎙️ Голос

Wake word «Джарвис», распознавание через Vosk или faster-whisper с Silero VAD, озвучка ответов Piper'ом.

🖥️ Управление системой

Воркспейсы, окна, скриншоты, громкость, блокировка — Hyprland, KDE, GNOME, i3, Sway и macOS.

🤖 LLM + bash-агент

Ollama локально или OpenAI/Anthropic/OpenRouter. Агент выполняет реальные команды с трёхслойным approval gate.

💬 Telegram-бот

Спрашивай Джарвиса из любого места — тот же мозг, тот же bash-агент, только в мессенджере.

⏰ Напоминания и диктовка

«Напомни через 10 минут» — и напомнит даже после перезапуска. Диктовка голосом в любое окно.

🩺 jarvis doctor

Диагностика окружения одной командой: конфиг, аудио, модели, LLM — приложи вывод к баг-репорту.

Быстрый старт

Из исходников — две команды.

# клонирование и установка (автоопределит Arch/Debian/Fedora/macOS)
git clone https://github.com/casha-cashu/jarvis.git && cd jarvis
bash install.sh
# запуск: source venv/bin/activate && jarvis run

Проверь окружение командой jarvis doctor — она покажет, что ещё нужно (модели, ключи, микрофон).
